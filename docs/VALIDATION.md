강체 팔다리의 두 삼각형 중복 warp를 단일 affine warp로 대체했고, 이후 굽힘 자산·보간을 추가했습니다.
최종 원시 결과: `synthetic-performance.json`. `synthetic-performance-before-optimization.json`은 굽힘 자산 추가 이전 기록이므로 최종과 동일 조건의 비교로 해석하지 않습니다.
중간 20자산 단독 측정은 뼈17.87/근육20.30ms였지만 위 표는 최종 24자산 재측정 결과이며 이전 수치를 최종 성능으로 인용하지 않습니다.
표의 FPS는 합성 처리량 환산이며 앱 FPS나 갤럭시북2 보장 성능이 아닙니다. 짧은 측정이므로 열/클록 영향도 미평가입니다.
위 합성 측정에서는 실제 캡처·추론 FPS를 측정하지 않았습니다. 후속 카메라 확인은 위 수정 검증 표에 별도 기록했습니다.
실제 인물 합성에서의 지연 p95 150ms 달성과 실제 디스플레이 지연은 미검증입니다.
