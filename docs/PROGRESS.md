## 후속 요청 반영: 통합 화면·손 선택·카메라 연결

- 운영/전시 창을 하나로 통합. 영상 위 근육/뼈 버튼, 설정 패널, F11/Esc, 같은 창의 모니터 이동 구현.
- 손목/검지/새끼손가락 좌표로 버튼 위 800ms 유지 선택. 진행 막대·손 커서·마우스 클릭 지원.
- 오래된/반복 포즈로 선택 시간이 늘지 않도록 제한. 손 소실/양손 충돌/손 교체 시 초기화, 선택 후 이탈해야 재선택.
- 카메라 번호 0 실패가 전체 카메라 미연결로 표시되던 문제 수정. 번호 0~5 실제 프레임 검색, 백엔드 대체, COM 초기화, 실패 핸들 해제 구현.
- Qt 장치 목록 순서와 OpenCV 번호를 대응시키지 않음. 실제 영상이 확인된 번호/백엔드/해상도 표시.
- 기본 실행 자동 연결. `--no-start`는 카메라 없이 UI만 열기. 수동 검색은 실행 중인 캡처를 종료하고 별도 worker에서 처리.
- 최신 자동 테스트 **43 passed (11.85초)**. 손 선택/좌표 변환/카메라 대체 경로 포함.
- 실제 카메라 번호 1 / DirectShow / 1280×720 수신. 15초 앱 실행 정상 종료, 로그 `docs/unified-camera-smoke.jsonl`.
- 사람 미검출 상태로 캡처 279장/추론 152회. 실제 인물의 손 선택이나 합성 품질을 검증한 것은 아님.
