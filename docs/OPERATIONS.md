# 갤럭시북2 실외 전시 운영

## 시작 전

1. 노트북 전원 연결, Windows 전원 모드 기록. 카메라를 연결하고 다른 카메라 사용 앱 종료.
2. 외부 모니터를 연결하고 Windows **확장** 모드 선택. 연결 순서에 의존하지 않습니다.
3. 그늘과 정면 채광을 확보합니다. 직사광·역광에서의 품질은 별도 점검합니다.
4. `run_windows.bat` 실행 → 카메라 자동 연결. 기본 요청은 1280×720/30 FPS입니다. 다른 영상이 나오면 설정의 장치 / 전시 탭에서 재검색 → 번호 선택 → 시작.
5. 실제 해상도/드라이버 FPS와 관찰 FPS 확인. 노출·화이트밸런스 조정은 현재 앱에서 지원하지 않습니다. 지원되는 카메라 제조사 도구에서만 조정합니다.
6. 통합 화면을 보며 정면 한 사람의 **얼굴과 양쪽 어깨**가 보이도록 카메라 높이·거리 조정. 전신을 담을 필요는 없습니다. 손이 양쪽 선택 버튼까지 닿도록 화면 속 위치를 확인합니다. 고정된 권장 거리/화각은 아직 없습니다.
7. 설정의 장치 / 전시 탭에서 전시 모니터를 이름·해상도·배율로 선택 → 이 화면을 선택 모니터로 이동 → 전체 화면.
8. 근육/뼈·거울·불투명도·상체/전신·정렬을 확인하고 설정 저장.

관리자와 전시는 **하나의 화면**을 사용합니다. 제목·설명·하단 안내를 제거하고 영상 위 근육/뼈 버튼만 표시합니다.
시작하면 전체 화면으로 열립니다. 화면 아래 **컨트롤**에서 운영 패널을 열고 닫습니다. F11은 전체 화면 전환, Esc는 전체 화면 해제입니다.
선택한 모니터가 분리되면 기본 모니터의 창 모드로 돌아옵니다. 재연결 후 이동할 모니터를 다시 선택합니다.
오류가 발생하면 운영자 원인을 확인하고 해결 후 다시 시작합니다. 자동 재시도로 USB/카메라를 반복 점유하지 않습니다.

## 손으로 근육·뼈 선택

1. 화면에 자신의 몸과 손이 보이도록 정면에 섭니다. 손의 흰색 원이 인식 위치를 표시합니다.
2. 화면 속 손을 원하는 **근육 / 뼈** 버튼에 겹쳐 **0.8초 유지**합니다. 아래 진행 막대가 차면 전환됩니다.
3. 손을 버튼 밖으로 뺀 뒤 다음 버튼을 선택합니다. 양손을 서로 다른 버튼에 동시에 두면 전환을 취소합니다.

손이 사라지거나 추적 결과가 오래되면 선택 진행이 초기화됩니다. 거울 보기와 영상 비율을 바꿔도 버튼과 손 좌표가 함께 맞춰집니다.
마우스로 같은 버튼을 클릭해도 전환됩니다. 원본만 보려면 설정의 표시 탭에서 원본 보기를 누릅니다.

## 브이로 화면 고정

1. 카메라에 한 손의 검지·중지를 펴서 브이 모양을 보여 줍니다. 몸이 안 잡히는 근접 상황에서도 손 모델은 동작합니다.
2. 약 0.5초 유지하면 **3 → 2 → 1**이 표시됩니다. 카운트가 시작되면 손을 내려도 되며 촬영 자세를 잡습니다. 시작 전 손을 풀면 준비가 취소됩니다.
3. 카운트가 끝나면 마지막 정상 영상과 합성을 고정하고 선택 버튼·손 커서·숫자를 숨깁니다. 카운트 도중 추적이 끊겨도 정상 합성 대신 원본으로 깜빡이지 않습니다. 사진 파일은 생성하지 않습니다.
4. **컨트롤 → 화면 재개**를 누르면 실시간 영상으로 돌아옵니다. 브이를 한 번 풀었다가 다시 해야 다음 카운트가 시작됩니다.

고정 중에는 설정을 바꾸거나 카메라를 정지해도 화면을 그대로 유지합니다. 재개 후에는 새로 들어온 프레임만 표시합니다.
실시간 표시도 짧은 추론 지연/사람 미검출에서는 완성 영상을 최대 약 0.5초 유지하여 원본과 번갈아 깜빡이는 전환을 줄입니다. 오래 추적을 잃으면 실시간 원본으로 돌아옵니다.
브이 인식 중에는 손으로 근육/뼈를 바꾸지 않습니다. 주변 사람의 브이도 카메라에 잡힐 수 있으므로 한 분씩 체험합니다.

## 운영 제약

얼굴에는 해부학 자산을 덮지 않습니다. 골반이 안 보이면 어깨 기준 가슴을 표시하고 아래쪽은 페이드 처리합니다.
화면 경계에 걸친 부위와 신뢰도가 떨어지는 부위도 흐려집니다. 사람이 완전히 사라지거나 결과가 만료되면 합성은 바로 숨깁니다.
양쪽 어깨까지 화면 밖으로 잘릴 정도로 가까우면 인식이 제한됩니다. 이때는 카메라 각도를 조절하거나 조금 뒤로 이동합니다.
근접 인식 성공 거리와 얼굴 보호 범위는 실제 인물·현장 조명에서 확인해야 합니다.

팔을 몸 앞에서 교차하거나 중앙으로 움직여도 표시합니다. 잠깐 가려진 팔꿈치/손목은 최대 0.3초 보정하며 후반 0.2초에 걸쳐 흐려집니다.
몸 전체/어깨가 사라지거나 크게 움직이면 보정을 해제합니다. 보정 좌표는 손 버튼 선택에 사용하지 않습니다.
현재는 전면 자산 기반 개발판입니다. 강한 측면/후면, 카메라를 향해 뻗어 극단적으로 짧아 보이는 팔/다리는 합성을 제한합니다.
옷이나 주변 사람으로 가려진 부위만 숨기도록 설계했지만 1인 추정이며 안정적인 사람 ID를 제공하지 않습니다.
주변 사람이 통과해도 카메라 중앙에 한 사람이 체험하도록 운영합니다. `num_poses=1`은 주변에 사람이 없다는 판정이 아닙니다.
정렬 슬라이더는 화면 오버레이의 교육용 보정이며 체형·근육량·내부 구조 측정이 아닙니다.

### 30분 연속 운전

```powershell
run_windows.bat --start --quit-after 1800 --metrics-log logs\galaxybook2-soak.jsonl
```

근육/뼈를 모두 실제 고품질 자산으로 운전합니다. 0/5/10/15/20/25/30분의 다음 값을 표로 옮깁니다.

| 분 | 모드 | 캡처/추론/합성 표시 FPS | 지연 평균/p95 | 결과 나이 | 드롭 | RAM/private | CPU/온도/클록 | 비고 |
|---|---|---|---|---|---|---|---|---|
| 0–30 | 미실시 | — | — | — | — | — | — | — |

로그는 CPU 점유율/working set/private bytes도 기록합니다. 온도·클록은 지원되는 하드웨어 도구로 별도 관찰합니다.
단계 시간은 최근 600개 표본 평균/p95, FPS는 최근 2초입니다. 메모리 증가 추세와 시간대별 열화 여부를 확인합니다.
목표: 합성 갱신 20 FPS 이상, 앱 내부 지연 p95 150ms 이하. 보장 사양이 아니며 현장 수치가 우선입니다.
카메라 노출/디스플레이를 포함한 체감 지연은 고속 촬영 등 별도 측정하되, 인물 기록은 명시적 동의 후에만 합니다.

### 시각·추적

두 모드 각각 정면 정지, 팔 들기, 팔꿈치 굽힘, 무릎 굽힘, 작은 몸통 회전, 나갔다 재진입,
팔만 가림, 다른 사람 통과, 느슨한 옷, 역광, 직사광, 흔들리는 배경을 관찰합니다.
양손 각각으로 근육/뼈 선택, 0.8초 이전 이탈, 양손의 상반된 선택, 거울 보기/fit/fill 변경 후 선택도 확인합니다.
근접 상체만 촬영, 골반·다리 잘림, 화면 경계에서 팔 이동, 얼굴 앞 팔 올리기에서도 얼굴 보존과 페이드 상태를 확인합니다.
좌/우 브이 유지, 카운트 중 손 내리기/손 바꾸기, 고정 중 손 움직임 무시, 컨트롤 재개, 재개 후 재촬영도 확인합니다.
7-A 조건(질감/부피, 확대 구조, 색·광원 일치, 늘어남/뒤집힘, 이음새/알파/앞뒤 순서)을 각각 통과/실패로 기록합니다.
현재 `docs/evidence`는 가상 장면이므로 이 항목을 대신 통과 처리할 수 없습니다.

정면 평가 지점(어깨/팔꿈치/무릎)을 수동 지정하여 오버레이 기준점과의 픽셀 거리/몸통 길이를 계산하고 중앙값을 기록합니다.
초기 목표는 5% 이하입니다. 내부 조직 정확도를 측정하는 값이 아닙니다. 기록 허용이 없으면 영상/랜드마크를 저장하지 않고 현장에서 관찰합니다.

### 장치·실패

- 외부 모니터 분리/재연결, 순서 변경, 중복 이름, 음수 좌표, 세로 화면, 125%/150% DPI.
- 카메라 점유/권한 거부/분리/read 실패, 모델 누락/손상, 자산 누락, 설정 손상.
- 통합 화면 안내가 적절하고 재시도 폭주 없이 복구되는지, 종료 후 카메라를 다른 앱에서 쓸 수 있는지.

### 목표 미달 시

segmentation은 기본 꺼져 있습니다. 자산 캐시/변형 비용 → 입력 크기(640→512→384) → 추론 주기 순서로 조정합니다.
입력 크기는 적용/재시작 버튼을 사용합니다. 변경 전후 동일 장면 시각 품질과 성능을 함께 기록합니다.
필수 질감·근육/뼈 모드를 제거하거나 불투명도로 결함을 감춰 통과 처리하지 않습니다.

## 멀리서 모드 선택

어깨가 인식되면 근육·뼈 버튼이 어깨 주변으로 이동합니다. 화면 속 손 커서를 원하는 버튼 위에 0.8초 유지하세요. 손을 내리면 선택 진행이 취소됩니다. 작은 인물의 버튼에도 최소 크기를 적용하며, 잠깐 손이 인식되지 않을 때는 150ms까지 진행을 유지합니다. 실제 현장의 조명과 거리에서 어깨·손 인식을 확인하세요.
