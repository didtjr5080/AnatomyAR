# 구조와 데이터 계약

## 처리

`CameraWorker(QThread)` → 제한 슬롯 → `TrackerWorker(QThread)` → MediaPipe LIVE_STREAM 콜백
→ 원본 프레임 매칭 → 신뢰도/EMA + 같은 프레임의 Gesture Recognizer VIDEO 추론 → 해부학 부위 배치 → premultiplied alpha 합성
→ 제한 출력 슬롯 → GUI 타이머 → 통합 창의 영상과 선택 UI 표시.

GUI에서 카메라 open/read나 모델 생성·추론·합성을 하지 않습니다. 원본 대기 표시용 BGR→RGB와 QImage 복사는 GUI에서 수행합니다.
캡처는 Qt signal의 DirectConnection으로 **잠금이 있는 단일 입력 슬롯**에만 전달합니다. 프레임별 GUI 이벤트를 쌓지 않습니다.
모델 콜백은 QWidget에 접근하지 않고 결과 슬롯에 소유된 좌표 배열을 넣습니다.

- FramePacket: frame_id, monotonic timestamp_ms, generation_id, 쓰기 불가 BGR 원본, 추론 크기와 sx/sy/padding.
- PosePacket: 같은 frame_id/timestamp/generation, 원본 픽셀 x/y/z와 visibility/presence, 포즈 추론 경과 시간, 실제 손 모델의 victory_hands.
- FrameMatcher: 최대 4장. 초과·역순·만료·이전 세대·종료 후 결과는 폐기합니다.
- 입력/콜백결과/출력/미리보기: 각 1개 슬롯. 추론 시간 딕셔너리는 최근 1초만 유지합니다.
- timestamp는 monotonic clock, 같은 ms가 반복되면 이전 값+1. wall clock 변경에 영향받지 않습니다.
- 새 추론 결과는 200ms 유효성을 검사합니다. 새 결과 사이에는 마지막 완성 영상 전체를 최대 500ms 유지하고 원본/합성을 번갈아 표시하지 않습니다. 이때 오래된 손 입력은 계속 차단합니다.
- 일시적인 사람 미검출도 마지막 정상 합성 전체를 잠시 유지합니다. 새 카메라 배경에 오래된 합성을 덧붙이지 않습니다. 지속적인 추적/카메라 실패에서는 원본 또는 빈 화면으로 복귀합니다.
- 모드/슬라이더는 AppState 버전만 변경합니다. 작업 중 모델을 재생성하지 않으며 같은 결과가 유효할 때 재합성합니다.
- 카메라/추론 입력 크기 변경은 명시적 적용으로 전체 세션을 재시작합니다. 세대 번호를 증가시켜 이전 콜백을 무시합니다.
- QImage는 `.copy()`로 NumPy 메모리와 독립된 소유권을 가집니다.
- 종료는 캡처 interrupt → matcher 닫기 → 모델 close → worker 종료 확인 순서. GUI 타이머로 기다려 메인 스레드를 막지 않습니다.

## 좌표

추론 입력은 원본 비율을 유지한 정사각형 letterbox입니다. 반올림 후 실제 sx/sy와 정수 padding을 기록합니다.
랜드마크를 추론 픽셀로 바꾼 후 padding을 빼고 각 축 scale로 나눕니다. 해부학 좌우는 사람 기준입니다.
미러링은 마지막 QImage 표시에서 수행하고, 라벨/디버그 기준점은 `W-1-x`로 같은 좌표를 사용합니다.
글자는 좌표만 뒤집고 읽을 수 있도록 정상 방향으로 그립니다.
fit/fill은 영상/오버레이를 이미 합친 이미지에 한 번만 적용합니다. QScreen 배치는 Qt 논리 좌표를 사용합니다.

## 손 선택과 카메라 검색

운영 설정은 같은 창 안에 여닫는 패널로 배치합니다. 영상 위 근육/뼈 버튼은 마우스와 손 선택을 공유합니다.
손목·검지·새끼손가락의 유효 좌표에서 손 위치를 구하고 영상과 같은 미러/fit/fill 변환을 적용합니다.
같은 손이 같은 버튼에 800ms 머물면 전환합니다. 진행 시간은 새로운 포즈 timestamp로만 증가합니다.
200ms를 넘긴 결과, 손 소실, 양손의 서로 다른 버튼 선택은 진행을 취소합니다. 선택 후 버튼을 벗어나야 다시 선택할 수 있습니다.
모드 변경은 기존 AppState를 갱신하며 모델이나 카메라를 다시 만들지 않습니다.

자동 카메라 선택은 번호 0~5의 실제 프레임을 확인합니다. 기존 번호 0 설정도 실패 시 다음 번호를 검사합니다.
각 번호에서 DirectShow 후 Media Foundation을 시도하며, 실패한 핸들은 해제합니다. 카메라 worker에서 COM을 초기화/해제합니다.
수동 재검색도 같은 검사를 별도 QThread에서 실행합니다. 기존 캡처를 먼저 종료하여 장치 점유 충돌을 피합니다.
Qt 장치 이름 목록의 순서를 OpenCV 번호로 간주하지 않습니다. 연결 완료는 open 성공뿐 아니라 첫 프레임 수신 이후에 표시합니다.

## 브이 카운트와 화면 고정

기본 시작은 전체 화면이며 제목·설명·주의문을 그리지 않습니다. 운영 상태/장치는 컨트롤 패널에 표시합니다.
Gesture Recognizer는 기존 worker에서 CPU VIDEO 모드로 처리하며 포즈 결과와 같은 원본/시간을 사용합니다. GUI에서는 모델 추론을 하지 않습니다.
Victory 점수 0.7 이상, 손 좌우 점수 0.6 이상, 화면 안의 실제 손목을 사용합니다. 몸 포즈가 없어도 손 모델 결과를 사용할 수 있습니다.
브이가 새로운 유효 프레임에서 500ms 유지되면 촬영을 확정합니다. 이후 3·2·1은 monotonic GUI 시각으로 3초 동안 진행하고 손을 내려도 완료합니다.
촬영 확정 전에는 반복/역순/200ms보다 오래된 결과, 손 변경/소실로 준비를 초기화합니다. 확정 후에는 추론 공백 때문에 카운트가 깜빡이거나 처음으로 돌아가지 않습니다.
카운트 중 최신 정상 합성 패킷 1개를 보관하고 추적이 끊긴 순간의 원본 대신 이 완성 영상을 고정합니다. 모드 버전이 다른 패킷은 재사용하지 않습니다.
카운트 중에는 임시 원본/빈 화면 전환을 막습니다. 정상 합성을 얻지 못한 장면은 정상적으로 전달된 원본을 고정할 수 있습니다.
입력 공백은 마지막 정상 결과의 **수신 시각**으로 판단합니다. 캡처 시각으로 검사하면 추론 지연을 입력 공백으로 오인하여 카운트가 반복 취소되는 문제를 수정했습니다.
고정 중에는 Controller가 표시를 갱신하지 않으며 영상 선택/카운트를 그리지 않습니다. 캡처·모델의 제한 슬롯은 유지되고 이미지 파일은 저장하지 않습니다.
컨트롤의 재개 버튼만 고정을 해제합니다. 대기 중인 출력과 현재 프레임을 버리고 재개 시각 이후의 영상부터 표시합니다.
재개 후 브이를 풀어야 다시 카운트할 수 있습니다. 브이 인식 중에는 손으로 모드를 바꾸는 선택을 잠시 막습니다.

## 제한 추적

confidence가 낮거나 NaN인 점은 필터에 정상값으로 누적하지 않습니다. 양쪽 어깨는 화면 안에 있어야 합니다.
팔다리/골반은 화면 밖 너비·높이의 35%까지 신뢰도가 충분한 좌표를 유지하여 화면 안에 걸친 부분을 자를 수 있게 합니다. 더 먼 추정값은 버립니다.
미검출/250ms 이상 끊김에서 EMA를 초기화합니다. 골반이 유효하지 않으면 양쪽 어깨로 가슴 영역을 배치하고 아래쪽 자산 알파를 점진적으로 줄입니다.
이 가슴 배치는 교육용 근사이며 안 보이는 골반을 측정한 결과가 아닙니다. 다리는 해당 관절이 유효할 때만 표시합니다.
머리 자산을 배치하지 않습니다. 어깨 폭과 코 위치(코가 없으면 어깨 기준 위치)로 얼굴 보호 타원을 만들고 모든 합성에 적용합니다.
얼굴 타원 안에는 원본을 유지하고 경계에 여유를 둬 부드럽게 연결합니다. 정밀 얼굴 분할은 아닙니다.
화면 테두리 8% 구간과 신뢰도 임계값 부근에서도 알파를 줄입니다.
팔꿈치/손목의 짧은 가림은 Compositor 전용 ArmContinuity에서 보정합니다. 마지막 유효 좌표를 어깨에 상대적으로 저장하고 작은 이동/크기 변화만 반영합니다.
가림 후 100ms까지 유지, 100~300ms 동안 페이드, 300ms에 폐기합니다. 보정 결과로 유효 시각을 갱신하지 않습니다.
사람/어깨 소실, 후면, 큰 위치/크기 변화, 먼 화면 밖 좌표, 250ms 초과 입력 공백에서는 보정을 해제합니다.
PosePacket과 손 선택에는 실제 필터 좌표만 전달합니다. 보정 팔로 손 버튼이 눌리지 않으며 새 결과/손 입력의 200ms 유효 시간도 유지합니다.
중앙 가로 영역 15–85%와 어깨 중심 이동으로 급격한 타깃 변경을 3프레임 재확인합니다. 사람 ID 보장은 아닙니다.
어깨 좌우 순서, 깊이차/투영 너비, 극단적으로 짧은 팔다리로 지원하지 않는 합성을 숨깁니다.
양팔 교차와 중심선 횡단은 숨김 조건에서 제거했습니다. 교차 부위는 75% 알파로 표시하며 기존 깊이 순서로 합성합니다.
팔의 중간 정도 원근 단축은 페이드로 표시하고 극단적인 단축만 숨깁니다. 정확한 앞뒤 가림 복원은 아닙니다.
후면/가림 판별은 휴리스틱이며 정확한 분할이나 내부 조직 가림을 보장하지 않습니다.
상완/허벅지 근육은 화면 관절각 기반 기본/굽힘 자산을 히스테리시스와 시간 보간으로 전환합니다.
이는 교육용 근사이며 근활성 측정이 아닙니다. 자세별 기준과 제한은 ASSETS.md에 기록했습니다.

## 상태

| 상태 | 진입 조건 | 통합 화면 상태 표시 | 영상 영역 |
|---|---|---|---|
| STOPPED | 시작 전 또는 모든 worker 종료 | 중지/다시 시작 | 빈 화면 또는 사용자가 고정한 화면 |
| STARTING | 모델·자산 검사 및 카메라 연결 | 준비 중/원인 | 빈 화면 |
| WAITING_PERSON | 유효 추론 결과에 사람 없음 | 사람 대기 | 원본 |
| TRACKING | 지원 부위와 유효 결과 | 추적 중 | 원본+합성 |
| DEGRADED | 부위 누락/회전/결과 만료 | 추적 제한·원인 | 가능한 부위만 또는 원본 |
| CAMERA_ERROR | open 또는 연속 5회 read 실패 | 연결/권한/점유 복구 안내 | 빈 화면 또는 사용자가 고정한 화면 |
| MODEL_ERROR | 모델/자산 누락·손상·추론 실패 | 구체적 오류 | 빈 화면 또는 사용자가 고정한 화면 |

장치 오류는 세션을 정지하며 자동 재시도하지 않습니다. 운영자 다시 시작으로 STARTING에 진입합니다.
선택한 모니터가 분리되면 추론 상태를 유지하고 통합 창을 기본 모니터의 창 모드로 복귀시킵니다. 재연결 후 이동할 모니터를 다시 선택합니다.
모니터는 serial/name/model로 식별하고 중복이면 저장 geometry로 구분합니다. 여전히 모호하면 자동 선택하지 않습니다.
모니터가 하나여도 F11로 전체 화면을 사용할 수 있습니다. Esc는 전체 화면만 해제합니다.

## 로그/성능

`--metrics-log`는 선택 사항입니다. 1초마다 시간·상태·처리량·단계 지연만 JSONL에 기록하며 5MB×3 파일로 제한됩니다.
카메라 영상/사진/랜드마크/스크린샷을 런타임에서 기록하거나 전송하는 기능은 없습니다.
지연은 OpenCV read가 반환된 시각부터 GUI 표시 제출까지입니다. 센서 노출/버퍼/실제 디스플레이 주사는 포함하지 않습니다.
FPS는 최근 2초 구간, 평균/p95는 최근 600개 단계 샘플입니다. 전체 30분 p95라고 해석하지 않습니다.
합성 표시 FPS와 원본 표시 FPS를 구분하며, 갱신이 없으면 FPS는 0으로 내려갑니다.

## 거리별 모드 선택

유효한 양쪽 어깨를 기준으로 버튼 위치와 간격을 계산하고 표시 영역 안으로 제한합니다. 어깨가 없으면 기존 가장자리 배치를 사용합니다. 좌우 반전과 fit/fill 좌표 변환을 손 커서와 공유합니다. 선택은 실제 최신 손 좌표만 사용하며 추론 결과의 수신 시각으로 대기 중 만료를 판단합니다. 입력 자체의 200ms 유효성 검사는 유지합니다. 손 인식 누락은 최대 150ms 동안 선택 진행만 유지하고, 손이 버튼 밖으로 이동하면 즉시 취소합니다. 합성 화면 유지 중에도 새 입력으로 선택할 수 있습니다.
