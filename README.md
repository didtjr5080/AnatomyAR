# 해부학 AR

[![Windows install and test](https://github.com/didtjr5080/AnatomyAR/actions/workflows/windows.yml/badge.svg)](https://github.com/didtjr5080/AnatomyAR/actions/workflows/windows.yml)

갤럭시북2(Core i5-12500H / Iris Xe / RAM 16GB)와 외부 전시 모니터를 대상으로 만든 Windows 교육용 AR 프로그램.
카메라 영상에 MediaPipe 관절점으로 배치한 근육·뼈 질감 자산을 합성합니다.
**현재는 실행 가능한 개발판입니다. 작업지시서 7-A의 시각 품질과 행사 장비 검수가 완료된 전시 배포판은 아닙니다.**

## 실행

Windows 10/11 **64비트**에서 실행합니다.

1. GitHub의 **Code → Download ZIP**으로 내려받거나 아래 명령으로 복제합니다.
2. ZIP은 먼저 압축을 풉니다.
3. **`run_windows.bat`을 더블클릭**합니다. 처음 실행하면 Python 3.12.8과 필요한 패키지를 자동 설치·검증한 뒤 앱을 엽니다. 첫 실행에는 인터넷이 필요합니다.
4. 설치가 끝난 뒤에는 같은 파일로 바로 실행하며 카메라가 자동으로 시작됩니다.

```powershell
git clone https://github.com/didtjr5080/AnatomyAR.git
cd AnatomyAR
.\run_windows.bat
```

Python을 미리 설치할 필요는 없습니다. 자동 설치 파일은 프로젝트의 `.tools`, `.python`, `.venv` 안에 보관하며 시스템 PATH/레지스트리는 변경하지 않습니다.
포즈·브이 모델과 PNG 자산은 저장소에 포함되어 있어 앱 실행 중 별도 모델 다운로드가 없습니다.

영상 위 **근육 / 뼈** 버튼에 화면 속 손을 **0.8초** 겹쳐 유지하면 전환됩니다. 마우스 클릭도 가능합니다.
시작 시 제목·안내문 없이 전체 화면으로 표시합니다. 화면 아래 **컨트롤**에서 운영 설정을 열 수 있습니다. **F11**은 전체 화면 전환, **Esc**는 전체 화면 해제입니다.
한쪽 손으로 **브이(✌)를 0.5초 유지**하면 **3 → 2 → 1**이 시작됩니다. 카운트가 시작되면 손을 내리고 촬영 자세를 잡아도 됩니다. **컨트롤 → 화면 재개**를 누를 때까지 사진처럼 고정됩니다.
짧은 지연에는 원본 영상과 합성을 번갈아 표시하지 않고 마지막 완성 영상을 유지합니다. 카운트 중 추적이 끊겨도 마지막 정상 합성을 고정합니다.
사진 파일은 저장하지 않습니다. 재개 후 브이를 한 번 풀었다가 다시 하면 다음 카운트를 시작합니다.
**얼굴은 카메라 원본으로 유지**합니다. 전신을 담을 필요 없이 **얼굴과 양쪽 어깨**가 보이게 서면 됩니다.
골반이 안 보이면 어깨를 기준으로 가슴을 표시하고 아래쪽을 페이드 처리합니다. 화면 가장자리와 낮은 신뢰도의 부위도 흐려집니다.
팔이 몸 앞을 지나거나 서로 겹쳐도 표시를 유지합니다. 관절이 잠깐 가려지면 최대 0.3초 보정하고 서서히 숨깁니다.
새 행사 장비도 `run_windows.bat`으로 준비할 수 있습니다. 가상환경은 PC 사이에 복사하지 않습니다. 설치만 하려면 `setup_windows.bat`, 오프라인 준비는 [설치](docs/INSTALL.md)를 따릅니다.

```powershell
.venv\Scripts\python.exe -m src.app
.venv\Scripts\python.exe -m pytest -q
```

## 구현 범위

- 한국어 통합 화면, 영상 위 근육·뼈 버튼과 손 선택 진행 표시, 같은 창 안의 운영 설정
- 로컬 손 제스처 모델로 브이 인식, 3·2·1 카운트, 메모리 내 화면 고정과 수동 재개
- 실제 영상 수신으로 카메라 자동 검색, 모니터 선택·전체 화면·Esc 해제·분리 시 기본 화면 복귀
- 근육·뼈·원본, 불투명도, 거울, 이름, 상체/전신, fit/fill, 대기 화면, 위치·크기·폭 보정
- CPU MediaPipe Lite LIVE_STREAM, 캡처/추론 worker, 제한 버퍼, 원본/결과 프레임 매칭
- 새 결과 200ms 유효성 검사, 짧은 표시 공백의 완성 영상 유지, confidence·시간 기반 평활화, 짧은 팔 가림 보정
- 로컬 모델 SHA-256 확인, 자산 로딩 검사, JSON 설정 검증·원자 저장, 오류 후 재시작
- 24개 투명 PNG 질감 자산, 원본 아틀라스·앵커·생성 프롬프트·출처 포함
- 근육 상완/허벅지 굽힘 자산 전환, 히스테리시스·시간 기반 보간 (교육용 근사)
- 영상 없는 선택형 성능 로그, 가상 좌표 기반 검증 이미지/영상

표현은 **3D 질감 렌더 이미지 기반 2.5D 합성**입니다. 실행 중 3D 메시를 렌더링하거나 내부 조직을 검출하지 않습니다.
현재 이미지는 imagegen으로 생성한 교육용 근사 자산이며, 실제 3D 모델에서 렌더했다고 주장하지 않습니다.

## 검증 상태

개발 PC Python 3.12.8에서 자동 테스트 **76개 통과**, 실제 Lite/손 제스처 모델 추론·worker 매칭·종료 통과.
Google 공식 브이 예제를 실제 모델에 입력하여 약 4초 후 화면 고정과 버튼 재개를 확인했습니다.
기본 카메라 번호 0이 실패하던 문제를 수정했고, 번호 1 / DirectShow에서 **1280×720 영상 수신과 정상 종료**를 확인했습니다.
통합 화면 배치, 손 선택, 근접 상체 합성과 얼굴 보존은 가상 좌표로 검증했습니다. 실제 인물의 근접 인식·손 동작 검수는 남아 있습니다.
**갤럭시북2 실외 성능, 실제 사람 정렬, 외부 모니터 연결/분리·DPI, 30분 운전은 미검증입니다.**
